# Portofolio Ignatius Felix Tjitradi

Website portofolio pribadi Ignatius Felix Tjitradi, mahasiswa semester 7 Teknik Informatika
Universitas Surabaya dengan fokus machine learning dan pengembangan game.

Situs ini statis (HTML, CSS, dan JavaScript vanilla), tanpa build step dan tanpa backend,
sehingga bisa langsung dipublikasikan di GitHub Pages.

## Fitur

- Desain responsif (mobile-first) dengan menu hamburger di layar kecil
- Navigasi smooth scroll dan penanda menu aktif sesuai posisi halaman
- Animasi muncul saat scroll (otomatis nonaktif bila pengguna memilih mengurangi animasi)
- Lightbox untuk memperbesar screenshot proyek
- Blok "Kontribusi saya" yang bisa dibuka-tutup di tiap proyek
- Tombol unduh CV dan tautan sertifikat
- Dapat dipakai dengan keyboard (skip link, fokus yang terlihat)

## Menjalankan di komputer

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
python -m http.server 8000
# lalu buka http://localhost:8000
```
